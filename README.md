# A Simple Calculator to Find the Area of a Circle

Created using **Android** and **Jetpack Compose**

## Features
- Input field with validation
- Two Buttons: Calculate and Exit
- Calculator for the Area of a Circle using the formula πr²

## Output
- Area of Circle in square inches

## Technology Stack
- Language: Kotlin  
- Framework: Jetpack Compose (Material 3)  
- Platform: Android
